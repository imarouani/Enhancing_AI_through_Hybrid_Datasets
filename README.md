# Hybrid Vehicle Classification with Synthetic Data (Stable Diffusion + ResNet-18)

This project explores how synthetic images generated by Stable Diffusion can enhance convolutional neural network (CNN) performance in multi-class vehicle classification, particularly under data-scarce conditions. Using a hybrid dataset of real and synthetic images, we fine-tuned a ResNet-18 model and demonstrated improved generalization.

## Overview

- **Objective:** Improve vehicle classification accuracy by combining real and AI-generated data.
- **Model:** ResNet-18 (pre-trained, fine-tuned for 10 vehicle classes)
- **Data:**
  - 10 classes (e.g., bus, SUV, taxi, truck, racing car)
  - 140 real images/class
  - 300 synthetic images/class (via Stable Diffusion)
  - Hybrid training with 50:50 and 30:70 mixes
- **Result:** Hybrid model achieved **88.3% test accuracy**, outperforming real-only (71.7%) and synthetic-only (34.2%) models.
